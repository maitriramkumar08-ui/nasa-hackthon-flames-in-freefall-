# Datasets

These are the nine files supplied for the project, kept in their original formats and with their original filenames. `manifest.csv` lists each file, a short description, its size, and a SHA-256 checksum so copies can be checked later.

The ZIP files contain NASA PSI investigation metadata. The CSV and spreadsheet files are supplied data files; the DOCX is an analysis report. No values have been converted or edited. The descriptions identify files by their supplied names and have not been independently validated against the source investigations.

The original files were copied into this folder from the contributor's Downloads directory. No commit or push was made.
